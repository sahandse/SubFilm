# SubFilm

A bilingual Persian/English subtitle discovery web app built with TypeScript, React, and Vite.

## Planned features
- Search subtitles by movie or series title
- Persian and English interface (RTL/LTR)
- Filter by language, release year, season, and episode
- Download subtitle files when provided by authorized sources
- Provider adapters for services such as OpenSubtitles and SubDL

## Development

```bash
npm install
npm run dev
```

## Environment
Provider API keys belong on a backend/server environment, never in client-side code. Check each provider's API terms, quotas, and redistribution rules before enabling downloads.
